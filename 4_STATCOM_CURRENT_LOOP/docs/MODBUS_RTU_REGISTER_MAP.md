# 双SCI Modbus RTU接口

## 链路

| 链路 | DSP角色 | 对端 | 引脚 | 参数 |
|---|---|---|---|---|
| SCI-A | 主站 | CPLD从站1 | GPIO12 TX，GPIO7 RX | 115200，8N1 |
| SCI-B | 从站2 | 上位机主站 | GPIO22 TX，GPIO23 RX | 115200，8N1 |

RTU帧使用CRC16，初值`0xFFFF`、多项式`0xA001`，CRC低字节先发。115200 bit/s时用固定1.75 ms静默时间判帧。DSP每20 ms轮询CPLD，响应超时20 ms、重试2次，500 ms没有有效响应判离线。

轮询全部14个CPLD输入寄存器的请求向量为`01 04 00 00 00 0E 71 CE`，可用于示波器或串口抓包核对。

## CPLD从站1

FC04输入寄存器（表内地址是PDU零基地址；部分上位机显示为30001起始编号）：

| 地址 | 内容 |
|---|---|
| `0000` | 协议版本`0x0105` |
| `0001` | 心跳/有效请求计数 |
| `0002` | VDC原始12位ADC码 |
| `0003` | VDC 256点平均ADC码 |
| `0004` | 温度脉冲计数/100 ms |
| `0005` | bit0链路在线、bit1 ADC有效、bit2温度有效、bit3总故障、bit4 PWM健康 |
| `0006-0007` | 32位故障，高字在低地址 |
| `0008` | 最近START/STOP命令回显 |
| `0009` | 有效Modbus帧计数 |
| `000A` | UART/CRC/残帧综合错误计数 |
| `000B` | UART停止位错误计数 |
| `000C` | Modbus CRC错误计数 |
| `000D` | t3.5不完整帧超时计数 |

FC03/FC06保持寄存器：`0100`为命令，`0=STOP`、`1=START`；`1000`为Vdc软件过压ADC原始码阈值，范围`1-3410`、默认`3410`，仅STOP可写。该配置不加入FC04周期轮询。CPLD仍硬封锁所有功率输出。

## DSP从站2

FC04输入寄存器：

| 地址 | 内容 |
|---|---|
| `0000` | 协议版本`0x0105` |
| `0001-0002` | DSP运行时间ms，高字在低地址 |
| `0003-0004` | ADC采样计数，高字在低地址 |
| `0005` | ADCINA0电网正半波原始值 |
| `0006` | ADCINA2交流电流原始值 |
| `0007` | ADCINA2零电流校准原始码 |
| `0008-0009` | CPLD VDC原始值、平均值 |
| `000A` | CPLD温度脉冲计数/100 ms |
| `000B` | CPLD状态 |
| `000C` | DSP保护锁存位：bit0电网峰值过压、bit1交流电流过流、bit2 PLL失锁、bit3 CPLD离线、bit4 CPLD上报故障 |
| `000D` | CPLD故障低16位，保持原12位故障映射 |
| `000E` | bit0在线、bit1超时/离线、bit2发生过CRC错、bit3发生过异常响应 |
| `000F` | PLL锁相标志 |
| `0010` | PLL频率，`0.01 Hz/LSB` |
| `0011` | PLL输入有效标志 |
| `0012` | STATCOM调试状态 |
| `0013` | ADC零漂校准状态 |
| `0014` | DSP-CPLD通信错误累计数 |
| `0015` | 上位机-DSP通信错误累计数 |
| `0016` | CPLD命令回显 |
| `0017` | CPLD UART停止位错误累计数 |
| `0018` | CPLD CRC错误累计数 |
| `0019` | CPLD不完整帧累计数 |
| `001A` | DSP SCI-A硬件格式错误累计数 |
| `001B` | DSP SCI-A接收溢出累计数 |
| `001C` | DSP等待CPLD回复超时累计数 |

保持寄存器：

- `0100`：上位机请求命令，`0=STOP`、`1=START`，支持FC03/FC06/FC10；FC10当前只接受数量1。
- `0101`：写`0xA55A`请求清除已经消失的DSP/CPLD锁存故障，仅支持单寄存器写入；START请求状态或错误密钥返回异常`03`。DSP同时重新武装“曾锁定后失锁”监测，因此STOP且PLL当前未锁定时可以清除历史失锁位并重新等待捕获；START仍要求PLL有效且已经锁定。FC03读取该地址时，`1`表示等待DSP转发/确认，`0`表示无待处理请求。
- `0102`：STOP下写`0xC33C`。DSP回显FC06后转发给CPLD；CPLD完整回包后复位UART、Modbus、ADC、温度监测及故障锁存逻辑。
- `0103`：STOP下写`0xD55D`。DSP先完整回显FC06，再使能看门狗执行本机复位。
- `0104`：STOP下写`0xCA1B`重新执行1024点ADC电流零漂校准；FC03读回校准状态`0/1/2=IDLE/RUNNING/DONE`。
- `1000`：CPLD Vdc软件过压绝对ADC原始码，默认/固件上限`3410`。DSP原样转发给CPLD；仅STOP可写。
- `1001`：DSP电网正半波峰值软件过压绝对ADC原始码，默认/固件上限`1313`；仅STOP可写。
- `1002`：DSP交流电流瞬时软件过流偏差计数，比较`abs(iac_raw-iac_zero_raw)`，默认/固件上限`51`；仅STOP可写。

三个保护阈值均只接受`1..编译默认原始码`，允许调低、不允许在现场调高越过固件安全上限。当前参数不掉电保存，DSP/CPLD复位后恢复默认值。所有V/A换算由上位机使用实物标定系数完成；固件不接收工程量阈值。

清故障请求尚未完成、PLL无效/未锁定、DSP有锁存故障时写START均返回异常`03`，避免维护动作、未锁相和带故障启动。电网电压与交流电流均在20 kHz ADC中断路径使用整数原始码连续3点越限后锁存；PLL保护只在系统曾经锁定后监测失锁，避免上电尚未捕获时误报。

CPLD温度保护不开放阈值下发：CPLD每100 ms直接比较传感器脉冲计数，固定参数当前为`5000 count/100 ms`且暂按“频率升高表示温度升高”处理；过温锁存到CPLD故障bit8，零脉冲传感器故障锁存到bit11。该固定值与方向必须完成传感器实物标定后再冻结。

除`1000-1002`外，`1003-13FF`仍为后续参数预留，访问必须返回异常`02`。三个阈值只在打开保护参数页、用户写入后读回时访问，不能加入每20 ms、29寄存器FC04监控，因而不增加周期通信负载。

## Modbus Poll最小检查

1. SCI-B连接上位机串口，选择RTU、115200、8N1、从站地址2。
2. 用FC04从地址`0000`读取29个寄存器，请求为`02 04 00 00 00 1D 30 30`，确认协议版本、ADC计数和运行时间变化。
3. 用FC06向`0100`写1，再用FC03读回请求值；随后读取FC04 `0016`确认CPLD回显。
4. STOP状态用FC03从`1000`读取3个阈值；用FC06单独写入一个较低安全测试值并FC03读回。START状态写阈值应收到异常`03`。
5. 写2应收到异常`03`；读预留地址应收到异常`02`。
6. 写START期间确认CPLD四路桥臂输出始终为0、`pwm_hold_o=1`、两个继电器输出保持不动作。

## 已完成的通信实测

SCI-B已在115200 bit/s、8N1下通过串口助手完成以下测试：

| 测试 | 请求 | 预期/实测结果 |
|---|---|---|
| 读协议版本 | `02 04 00 00 00 01 31 F9` | `02 04 02 01 00 FC A0` |
| 读全部输入寄存器 | `02 04 00 00 00 17 B0 37` | 返回`02 04 2E`开头的51字节完整帧 |
| 读命令寄存器 | FC03，地址`0100`，数量1 | 正确返回当前STOP/START请求值 |
| 写STOP | `02 06 01 00 00 00 88 05` | 原帧回显 |
| 写START | `02 06 01 00 00 01 49 C5` | 原帧回显 |
| 写非法值2 | `02 06 01 00 00 02 09 C4` | `02 86 03 F2 61` |
| 读非法地址 | `02 04 10 00 00 01 35 39` | `02 84 02 32 C1` |

SCI-A已通过串口助手确认能连续发送完整的CPLD请求帧，包括START命令`01 06 01 00 00 01 49 F6`。V0x0105保持14寄存器CPLD轮询与29寄存器DSP周期监控长度不变，需使用本轮生成的DSP OUT与CPLD POF及适配V0x0105的上位机配套验证。
