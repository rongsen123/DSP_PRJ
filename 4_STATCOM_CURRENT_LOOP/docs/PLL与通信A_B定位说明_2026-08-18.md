# PLL与通信A/B定位说明（2026-08-18）

## 镜像

- A版标准镜像：`Debug/4_STATCOM_CURRENT_LOOP.out`
  - `STATCOM_FAST_PROTECTION_DIAGNOSTIC_BYPASS=0`
  - 20 kHz ADC ISR执行交流电流、电网电压快速保护。
- B版诊断镜像：`Debug/4_STATCOM_CURRENT_LOOP_DIAG_B_NO_FAST_PROTECTION.out`
  - 编译时`STATCOM_FAST_PROTECTION_DIAGNOSTIC_BYPASS=1`
  - 20 kHz ADC ISR不执行快速保护；电流换算和ADC校零临时回到4 kHz前台，
    用于复现3号工程的ISR负担。

最终源码宏已恢复为0，后续普通CCS Build生成的仍是A版。

## 安全边界

两版均保持`STATCOM_POWER_OUTPUT_ENABLED=0`，DSP无PWM输出；CPLD桥臂、
PWM HOLD和继电器硬封锁不变。B版没有20 kHz电压/电流软件保护，只允许
低压、无功率输出的锁相定位，禁止用于带功率测试。

## 上板顺序

1. 保持同一CPLD POF、同一电网采样输入、同一上位机和接线。
2. 先烧写A版，复位后运行至少60 s，记录PLL锁定、频率及下列变量。
3. 断电后烧写B版，使用完全相同条件重复测试。
4. 测试时关闭CCS连续刷新；需要读变量时只做一次暂停快照。

必须记录：

```text
adc_sample_count
adc_processed_count
adc_pll_sample_count
adc_queue_overflow_count
adc_overflow_count
adc_isr_max_cycles
g_gridPllLocked
g_gridPllFrequencyHz
g_gridPllFrequencyLimited
```

正常节拍应满足：

```text
adc_processed_count ≈ adc_pll_sample_count ≈ adc_sample_count / 5
adc_queue_overflow_count = 0
adc_overflow_count = 0
adc_isr_max_cycles < 1350
```

判断：B锁定而A不锁定，说明20 kHz新增路径的ISR时序/前台排队是主因；两版
都不锁定，应转查输入波形、采样缩放和PLL锁定判据；两版都锁定，则重点排查
CCS实时刷新及上位机通信负载对测试过程的干扰。
