# 双SCI Modbus RTU接口

## 链路

| 链路 | DSP角色 | 对端 | 引脚 | 参数 |
|---|---|---|---|---|
| SCI-A | 主站 | CPLD从站1 | GPIO12 TX，GPIO7 RX | 115200，8N1 |
| SCI-B | 从站2 | 上位机主站 | GPIO22 TX，GPIO23 RX | 115200，8N1 |

RTU帧使用CRC16，初值`0xFFFF`、多项式`0xA001`，CRC低字节先发。115200 bit/s时用固定1.75 ms静默时间判帧。DSP每20 ms轮询CPLD，响应超时20 ms、重试2次，500 ms没有有效响应判离线。

轮询全部14个CPLD输入寄存器的请求向量为`01 04 00 00 00 0E 71 CE`，可用于示波器或串口抓包核对。

## CPLD从站1

FC04输入寄存器（表内地址是PDU零基地址；部分上位机显示为30001起始编号）：

| 地址 | 内容 |
|---|---|
| `0000` | 协议版本`0x0103` |
| `0001` | 心跳/有效请求计数 |
| `0002` | VDC原始12位ADC码 |
| `0003` | VDC 256点平均ADC码 |
| `0004` | 温度脉冲计数/100 ms |
| `0005` | bit0链路在线、bit1 ADC有效、bit2温度有效、bit3总故障、bit4 PWM健康 |
| `0006-0007` | 32位故障，高字在低地址 |
| `0008` | 最近START/STOP命令回显 |
| `0009` | 有效Modbus帧计数 |
| `000A` | UART/CRC/残帧综合错误计数 |
| `000B` | UART停止位错误计数 |
| `000C` | Modbus CRC错误计数 |
| `000D` | t3.5不完整帧超时计数 |

FC03/FC06保持寄存器：`0100`为命令，`0=STOP`、`1=START`。CPLD第一阶段支持FC03、FC04、FC06；START只改变回显。

## DSP从站2

FC04输入寄存器：

| 地址 | 内容 |
|---|---|
| `0000` | 协议版本`0x0103` |
| `0001-0002` | DSP运行时间ms，高字在低地址 |
| `0003-0004` | ADC采样计数，高字在低地址 |
| `0005` | ADCINA0电网正半波原始值 |
| `0006` | ADCINA2交流电流原始值 |
| `0007` | 交流电流，`0.01 A/LSB`，有符号补码 |
| `0008-0009` | CPLD VDC原始值、平均值 |
| `000A` | CPLD温度脉冲计数/100 ms |
| `000B` | CPLD状态 |
| `000C-000D` | CPLD 32位故障，高字在低地址 |
| `000E` | bit0在线、bit1超时/离线、bit2发生过CRC错、bit3发生过异常响应 |
| `000F` | PLL锁相标志 |
| `0010` | PLL频率，`0.01 Hz/LSB` |
| `0011` | PLL输入有效标志 |
| `0012` | STATCOM调试状态 |
| `0013` | ADC零漂校准状态 |
| `0014` | DSP-CPLD通信错误累计数 |
| `0015` | 上位机-DSP通信错误累计数 |
| `0016` | CPLD命令回显 |
| `0017` | CPLD UART停止位错误累计数 |
| `0018` | CPLD CRC错误累计数 |
| `0019` | CPLD不完整帧累计数 |
| `001A` | DSP SCI-A硬件格式错误累计数 |
| `001B` | DSP SCI-A接收溢出累计数 |
| `001C` | DSP等待CPLD回复超时累计数 |

保持寄存器：

- `0100`：上位机请求命令，`0=STOP`、`1=START`，支持FC03/FC06/FC10；FC10当前只接受数量1。
- `0101`：写`0xA55A`请求清除CPLD已经消失的锁存故障，仅支持单寄存器写入；START请求状态或错误密钥返回异常`03`。FC03读取该地址时，`1`表示等待DSP转发/确认，`0`表示无待处理请求。
- `0102`：STOP下写`0xC33C`。DSP回显FC06后转发给CPLD；CPLD完整回包后复位UART、Modbus、ADC、温度监测及故障锁存逻辑。
- `0103`：STOP下写`0xD55D`。DSP先完整回显FC06，再使能看门狗执行本机复位。
- `0104`：STOP下写`0xCA1B`重新执行1024点ADC电流零漂校准；FC03读回校准状态`0/1/2=IDLE/RUNNING/DONE`。

清故障请求尚未完成时写START同样返回异常`03`，避免维护动作与启动命令交叉执行。

`1000-13FF`为后续参数预留，当前访问必须返回异常`02`。

## Modbus Poll最小检查

1. SCI-B连接上位机串口，选择RTU、115200、8N1、从站地址2。
2. 用FC04从地址`0000`读取29个寄存器，请求为`02 04 00 00 00 1D 30 30`，确认协议版本、ADC计数和运行时间变化。
3. 用FC06向`0100`写1，再用FC03读回请求值；随后读取FC04 `0016`确认CPLD回显。
4. 写2应收到异常`03`；读预留地址应收到异常`02`。
5. 写START期间确认CPLD四路桥臂输出始终为0、`pwm_hold_o=1`、两个继电器输出保持不动作。

## 已完成的通信实测

SCI-B已在115200 bit/s、8N1下通过串口助手完成以下测试：

| 测试 | 请求 | 预期/实测结果 |
|---|---|---|
| 读协议版本 | `02 04 00 00 00 01 31 F9` | `02 04 02 01 00 FC A0` |
| 读全部输入寄存器 | `02 04 00 00 00 17 B0 37` | 返回`02 04 2E`开头的51字节完整帧 |
| 读命令寄存器 | FC03，地址`0100`，数量1 | 正确返回当前STOP/START请求值 |
| 写STOP | `02 06 01 00 00 00 88 05` | 原帧回显 |
| 写START | `02 06 01 00 00 01 49 C5` | 原帧回显 |
| 写非法值2 | `02 06 01 00 00 02 09 C4` | `02 86 03 F2 61` |
| 读非法地址 | `02 04 10 00 00 01 35 39` | `02 84 02 32 C1` |

SCI-A已通过串口助手确认能连续发送完整的CPLD请求帧，包括START命令`01 06 01 00 00 01 49 F6`。V0x0103新增14寄存器CPLD轮询及错误分类，需使用本轮生成的DSP OUT与CPLD POF配套上板验证。
