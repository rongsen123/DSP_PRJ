# 单相STATCOM调试上位机设计与通信协议规范 V1.0

## 1. 文档用途

本文档用于指导其他AI或开发人员实现Windows调试上位机。上位机通过DSP的SCI-B读取采样、锁相、CPLD状态和故障信息，并写入START/STOP调试命令。

本规范对应固件：

- DSP工程：`3_STATCOM_PI_PR`
- DSP型号：TMS320F28062
- DSP Modbus从站地址：2
- CPLD型号：EPM1270
- 协议版本寄存器地址：`0x0000`，当前值：`0x0102`
- 当前阶段：通信、ADC和SOGI-PLL调试，功率输出硬封锁

机器可读的配套地址表为`STATCOM上位机寄存器映射_V1.json`，实现时应以该文件集中生成寄存器模型，禁止在多个页面重复硬编码地址。

上位机V1不实现电流环、电压环、PWM控制、参数掉电保存和高速ADC波形上传。

## 2. 系统关系

```text
通用串口/USB转串口
        │ 115200 8N1 Modbus RTU
        ▼
上位机主站 ───── DSP SCI-B从站2
                       │
                       │ DSP SCI-A作为Modbus主站
                       ▼
                 CPLD从站1
```

上位机只连接DSP从站2，不直接访问CPLD。CPLD数据由DSP轮询后映射到DSP输入寄存器。

## 3. 推荐软件技术方案

推荐Windows桌面程序采用以下方案之一：

1. Python：PySide6 + pyserial/pymodbus + CSV日志。
2. C++：Qt Widgets/Qt SerialPort +独立Modbus RTU模块。

推荐优先使用Python/PySide6完成第一版，便于快速修改寄存器和换算规则。禁止在UI线程中阻塞读串口；通信线程、数据模型和界面刷新必须分离。

## 4. 上位机必须具备的功能

### 4.1 串口连接

- 枚举可用串口。
- 配置串口号，固定115200 bit/s、8数据位、无校验、1停止位。
- DSP从站地址默认2，允许在高级设置中修改。
- 显示连接状态、最后一次成功响应时间、连续失败次数和通信错误累计数。
- 断线后可以自动重连，但自动重连后绝对不能自动发送START。
- 提供“连接”“断开”“重新扫描串口”按钮。

### 4.2 实时总览

至少显示：

- DSP在线状态。
- DSP运行时间。
- ADC采样计数和采样计数变化率。
- 电网正半波ADC原始码、ADC引脚电压和暂定实际电压。
- 交流电流原始码和交流电流A。
- CPLD直流电压原始码、平均码和标定后的电压（仅标定有效时显示）。
- 温度100 ms脉冲计数和标定温度（仅标定有效时显示）。
- DSP-CPLD链路状态。
- PLL输入有效、锁相状态和频率。
- ADC零漂校准状态。
- CPLD总故障、32位故障详情和CPLD系统状态。
- 上位机请求命令和CPLD实际回显。

### 4.3 趋势曲线

V1趋势曲线显示轮询值，不是20 kHz原始波形。建议默认10 Hz刷新，可选1～20 Hz。

建议曲线：

- 交流电流A。
- PLL频率Hz。
- CPLD VDC平均ADC码或标定电压。
- 电网正半波估算电压。
- 温度计数或标定温度。

保留最近60 s、5 min和30 min三种时间窗口。断线区间必须显示为空白或无效，不能用最后值补线。

### 4.4 START/STOP命令

- STOP按钮始终可见，START按钮必须二次确认。
- START写入保持寄存器`0x0100=1`。
- STOP写入保持寄存器`0x0100=0`。
- 写入后使用FC03回读DSP请求值，再检查FC04输入寄存器`0x0016`的CPLD回显。
- 界面必须分别显示“DSP请求值”和“CPLD回显值”，不能只显示一个运行按钮。
- 命令状态应分为：未发送、DSP已接受、CPLD已回显、超时/不一致。
- 当前固件即使CPLD回显START，PWM和继电器仍处于硬封锁；上位机不得显示“功率已运行”，只能显示“调试START已回显”。

### 4.5 故障与事件

- 逐位解析CPLD 32位故障。
- 故障发生、消失、通信断线、重新连接、START/STOP写入都写入事件日志。
- 事件至少包含本机时间、事件类型、原始寄存器值和中文描述。
- 故障位是CPLD锁存结果，界面不得因当前物理信号恢复就擅自清除。
- 当前协议没有清故障寄存器，V1不得提供可用的“清故障”按钮。

### 4.6 原始寄存器和通信诊断

- 显示最近一次发送帧和接收帧的十六进制内容。
- 显示CRC错误、超时、异常响应、非法地址和连续失败次数。
- 支持手动读取FC03/FC04，但默认限制在本文定义的地址范围。
- 显示寄存器原始十六进制、无符号十进制、有符号十进制和解析值。
- 提供导出诊断快照功能。

### 4.7 数据记录

- 支持开始/停止CSV记录。
- 每行包含本机时间戳、DSP运行时间、全部原始寄存器、换算值和有效标志。
- CSV列名必须包含单位，例如`iac_A`、`pll_frequency_Hz`、`cpld_vdc_raw_count`。
- 同时保存原始值和换算值，不能只保存换算结果。
- 日志中保存当前标定系数和协议版本。

## 5. Modbus RTU规范

| 项目 | 数值 |
|---|---|
| 模式 | Modbus RTU |
| 上位机角色 | 主站 |
| DSP角色 | 从站 |
| DSP从站地址 | 2 |
| 波特率 | 115200 bit/s |
| 数据格式 | 8N1 |
| CRC | CRC16/Modbus |
| CRC初值 | `0xFFFF` |
| CRC多项式 | `0xA001` |
| CRC发送顺序 | 低字节在前 |
| 帧间隔 | 固定`t3.5=1.75 ms` |
| 支持功能码 | FC03、FC04、FC06、FC10 |
| 支持异常码 | `01`非法功能、`02`非法地址、`03`非法值 |

所有16位寄存器在Modbus数据区内高字节先发送。32位数据使用“高16位在低地址、低16位在高地址”。

### 5.1 地址表示规则

本文使用PDU零基地址。例如：

- 本文`0x0000`在某些Modbus软件中显示为输入寄存器30001。
- 本文`0x0100`在某些软件中显示为保持寄存器40257。
- 编程时应向Modbus库传入实际PDU地址`0x0000`或`0x0100`，不要把30001/40257直接作为协议地址发送。

### 5.2 推荐轮询

连接后先执行：

1. FC04读取`0x0000`数量1，确认协议版本为`0x0102`。
2. FC04读取`0x0000`数量23，一次取得全部实时输入寄存器。
3. 默认每100 ms轮询一次；允许用户设置50～1000 ms。
4. FC03读取`0x0100`数量1，建议500 ms或命令操作后立即读取。

不要以20 kHz或1 ms周期轮询。当前串口链路只用于监控和低速命令，不用于实时控制。

### 5.3 已知请求帧

```text
读取DSP全部23个输入寄存器：02 04 00 00 00 17 B0 37
写START：                  02 06 01 00 00 01 49 C5
写STOP：                   02 06 01 00 00 00 88 05
读取DSP请求命令：          02 03 01 00 00 01 85 C5
```

实现时仍必须动态计算CRC，不能把固定帧作为唯一通信方式。

## 7. DSP从站2保持寄存器

### 7.1 当前有效地址

| 地址 | FC03读取 | FC06写入 | FC10写入 | 内容 |
|---|---|---|---|---|
| `0100` | 支持 | 支持 | 支持，数量只能为1 | `0=STOP`、`1=START` |
| `0101` | 支持，`0=空闲/1=待转发` | 支持，写`0xA55A` | 不支持 | 清除CPLD已经消失的锁存故障；必须处于STOP请求状态 |
| `0102` | 不支持 | 支持，写`0xC33C` | 不支持 | 复位CPLD通信与内部状态机；必须处于STOP请求状态 |
| `0103` | 不支持 | 支持，写`0xD55D` | 不支持 | 受控软复位DSP；必须处于STOP请求状态 |
| `0104` | 支持，返回ADC校零状态 | 支持，写`0xCA1B` | 不支持 | 重新执行1024点零漂校准；必须STOP且当前不在RUNNING |

清故障或复位时错误密钥或START请求状态返回异常`03`。访问未实现地址或用FC10写维护寄存器返回异常`02`。

### 7.2 预留但尚未实现

| 地址范围 | 计划用途 | V1界面要求 |
|---|---|---|
| `1000-10FF` | 保护阈值、软起参数 | 禁止读写，显示“固件未实现” |
| `1100-11FF` | PLL参数 | 禁止读写 |
| `1200-12FF` | 电流环参数 | 禁止读写 |
| `1300-13FF` | 电压环参数 | 禁止读写 |

上位机不能在收到异常`02`后生成假参数或使用本地默认值冒充DSP实际值。

## 8. 数据类型与模拟量换算

### 8.1 通用解码

```text
U16 = register & 0xFFFF
S16 = U16                 （U16 < 0x8000）
S16 = U16 - 65536         （U16 >= 0x8000）
U32 = (high_register << 16) | low_register
```

### 8.2 ADC引脚电压

DSP ADC参考电压为3.0 V，12位ADC：

```text
adc_pin_voltage_V = raw_count × 3.0 / 4096.0
```

此值表示DSP ADC引脚电压，不等于功率侧实际电压或电流。

### 8.3 ADCINA0电网正半波

当前固件暂定硬件比例：

```text
grid_halfwave_estimated_V = register_0005 × 0.2741878
```

注意：

- `0005`定义为电网正半波原始采样，不是平滑直流母线电压。
- `0.2741878 V/count`来自当前原理图比例计算，必须经过标准电压源实测校准。
- 上位机应同时显示ADC引脚电压、原始码和“暂定电网正半波电压”。
- 未完成实测标定前，换算值旁必须显示“未标定/估算”。

推荐上位机支持线性标定：

```text
physical_value = gain × raw_count + offset
```

默认`gain=0.2741878`、`offset=0`，但`calibration_valid=false`。

### 8.4 交流电流

优先使用寄存器`0007`：

```text
iac_A = signed16(register_0007) / 100.0
```

DSP内部已经完成零漂扣除和`0.09887695 A/count`换算。寄存器`0006`是未扣零漂的ADC原始码，上位机没有当前零漂偏置寄存器，因此不能仅凭`0006`准确恢复电流。`0006`只用于观察ADC工作和零点漂移。

### 8.5 CPLD直流电压

`0008/0009`目前只有ADS7818原始码和256点平均码，没有可靠的“V/count”标定系数。

V1要求：

- 默认显示单位`count`，不得默认显示V。
- 提供可选两点标定页，但只有用户完成标定并确认后才显示V。
- 两点标定公式：

```text
gain = (V2 - V1) / (code2 - code1)
offset = V1 - gain × code1
vdc_V = gain × code + offset
```

- 标定文件必须保存板卡编号、两组原始码、标准电压、gain、offset、时间和操作者。
- 当`calibration_valid=false`时，电压字段显示`-- V`，不能套用DSP ADCINA0的比例。

### 8.6 温度

`000A`表示100 ms内传感器输出脉冲数，不是摄氏度。

在取得传感器标定曲线前：

- 显示`pulse/100 ms`。
- 摄氏度显示为`-- ℃`。
- 禁止使用未经确认的线性系数。

后续允许使用分段线性表或多项式：

```text
temperature_C = calibration_function(pulse_count)
```

### 8.7 PLL频率

```text
pll_frequency_Hz = register_0010 / 100.0
```

只有`pll_signal_valid=1`时频率才作为有效测量值；只有`pll_locked=1`时界面才显示“已锁相”。信号无效时保留原始寄存器用于诊断，但工程值应显示为无效。

### 8.8 当前未提供的数据

当前寄存器表没有提供以下量，上位机不得虚构：

- PLL相角/theta。
- SOGI alpha、beta实时量。
- ADCINA1直流电流原始值和工程量。
- 20 kHz连续ADC波形缓存。
- 电流环、电压环Kp/Ki实际值。
- 功率输出允许或PWM占空比。

如后续需要波形，应设计DSP采样缓存和分块上传协议，不能靠100 ms Modbus轮询重构20 kHz波形。

## 11. 通信状态机和错误处理

### 11.1 连接状态

建议状态机：

```text
DISCONNECTED
  → CONNECTING
  → VERSION_CHECK
  → ONLINE
  → DEGRADED（偶发超时/CRC）
  → OFFLINE（连续失败）
```

推荐策略：

- 单次请求超时：100 ms。
- 请求重试：最多2次。
- 连续3个轮询周期失败：界面标记DSP离线。
- 成功读取完整寄存器块后恢复ONLINE。
- 离线时所有实时数值标记为无效，不清零、不伪造0值。
- 禁止在重连时重发上一次START。

### 11.2 Modbus异常

- 异常`01`：记录“固件不支持该功能码”。
- 异常`02`：记录“寄存器未实现/地址错误”。
- 异常`03`：记录“数值或数量非法”。
- CRC错误：丢弃整帧，不更新数据模型。
- 从站地址不匹配：丢弃。
- 字节数与请求数量不匹配：丢弃并记录格式错误。

### 11.3 数据一致性

每次FC04块读取成功后一次性更新UI数据模型，禁止逐寄存器更新造成高低字跨帧混用。

可用以下方式判断数据活性：

- `uptime_ms`持续增加。
- `adc_sample_count`在100 ms轮询间隔内约增加2000。
- DSP-CPLD在线时`cpld_status.bit0=1`。
- 通信错误计数的增量用于报警，计数回绕按U16处理。

### 13.1 顶部固定区

## 14. 安全要求

- 软件启动后默认STOP显示，但不要在未连接时伪造设备STOP回读。
- START必须弹出确认，提示“当前仅为调试命令，不代表功率输出已运行”。
- STOP不需要确认，并应中断排队中的普通读取，优先发送。
- 通信断开不能显示RUN正常；应显示命令状态未知。
- 上位机不得根据`CPLD回显=1`推断PWM已输出。
- 不提供绕过故障、强制PWM、继电器动作或修改保护参数的隐藏功能。
- 参数范围检查必须同时在UI层和协议层实施。

## 17. 版本兼容规则

- 连接后必须先读`0000`。
- 上位机支持的主版本与设备主版本不一致时，禁止写命令，只允许显示原始寄存器。
- 次版本变化时允许读取已知寄存器，但未知位和未知枚举必须原样显示。
- 后续增加寄存器时只能追加或通过协议版本区分，不能静默改变现有地址的单位和含义。
