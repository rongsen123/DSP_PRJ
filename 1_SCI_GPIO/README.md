# 1_SCI_GPIO

## 工程功能

本工程运行于 TMS320F28062，通过 SCI-A 接入板上光纤收发链路。电脑端经光纤转 RS-485、RS-485 转 USB 模块与设备通信。通信采用主站请求、DSP 从站应答的半双工问答方式，避免链路收发冲突。

主要功能：

- SCI-A 接收与发送 FIFO 中断。
- 协议帧头识别、长度检查、数据接收及异或校验。
- 合法请求帧的中断式回送，用于链路通信测试。
- 发送期间暂停接收，等待 `TXEMPTY` 后清理接收 FIFO 并恢复下一轮接收。
- 完成一次正确收发后翻转 GPIO10，提供 LED 状态指示。

## 硬件与串口配置

| 项目 | 配置 |
| --- | --- |
| 目标芯片 | TMS320F28062 |
| 系统时钟 | 90 MHz |
| SCI 外设时钟 | 22.5 MHz |
| 波特率 | 230400 bit/s |
| 数据格式 | 8 数据位、无校验、1 停止位 |
| SCIRXDA | GPIO7 |
| SCITXDA | GPIO12 |
| 状态 LED | GPIO10、GPIO55 |

## 通信协议

帧格式：

```text
帧头1 | 帧头2 | 数据长度 | 数据区 | 校验
 AA   |  55   |   LEN    | DATA   | XOR
```

- 数据区最大长度为 32 字节。
- 校验值为帧头、长度和全部数据字节的逐字节异或值。
- 当前协议采用类似 Modbus RTU 的一问一答时序，但不是标准 Modbus RTU，未使用 Modbus 地址、功能码或 CRC16。

测试帧示例：

```text
发送：AA 55 01 01 FF
应答：AA 55 01 01 FF
```

## 软件结构

- `main.c`：系统初始化、应答启动及 LED 状态处理。
- `app/sci.c`：SCI 初始化、接收协议状态机、RX/TX FIFO ISR 和发送状态管理。
- `app/led.c`：LED GPIO 初始化。
- `source/`、`headers/`、`include/`：F2806x 设备支持代码及寄存器定义。
- `cmd/`：F28062 内存和外设寄存器链接配置。

## 编译方法

1. 使用 CCS 12.3.0 导入本目录下的既有 CCS 工程。
2. 确认编译器为 TI C2000 22.6.0.LTS，目标器件为 TMS320F28062。
3. 选择 `Debug` 配置并执行 Build Project。
4. 使用 XDS100 USB 连接目标板下载和调试。

`Debug/` 目录及生成的 `.out`、`.map` 等文件由 Git 忽略，不属于源码提交内容。
